# Hallmark Skill

Use this skill whenever designing or implementing user interfaces (Blade, React, React Native) to ensure non-generic, high-craft aesthetics.

## Core Commands
- `hallmark build`: Select macrostructure layout and apply theme.
- `hallmark audit`: Audit existing UI components against slop patterns.
- `hallmark redesign`: Restructure interface layout while preserving state/props.
- `hallmark study`: Analyze reference screenshot/URL and extract typographic & color tokens.

## Principles
- Dynamic layouts over centered card grids.
- Subtle contrast elevation over harsh borders.
- Tactile feedback state for touch and click handlers.
